# 页面设计系统 v1.0（固定）

目标：复刻样本《从第一性原理学会多项式不可约》的**排版语言**，让任意学科课程具有稳定的视觉识别，而不是每本重新设计。

| 区域 | 固定设计 | 可改内容 |
|---|---|---|
| 纸张 | A4 纵向 210 × 297mm | 不改 |
| 页面 | 左右 19.5mm，上 19.5mm，下 21.5mm | 不改 |
| 字体 | 正文 Noto Serif CJK SC；标题 Noto Sans CJK SC；公式由 TeX 排版 | 内容、术语 |
| 封面 | 上方深蓝大面积色块 + 右侧青绿圆与橙点 + 两道线圈 | 主标题、副标题、课程路线 |
| 配色 | 深蓝 `#193B54`、青绿 `#167F87`、琥珀 `#B9873C`、浅蓝 `#F0F6F8` | 不改 |
| 正文 | 白底，12pt 中文，约 1.28 倍行距，首行缩进 2 汉字 | 公式、图表内容 |
| 标题 | 章节和小节统一青绿无衬线粗体；三级标题深蓝 | 节标题 |
| 页眉页脚 | 左侧“学科・从零开始”，右侧章节主题，细分隔线，下方居中页码 | 文本 |
| 题目框 | 青绿标题条＋白底描边，可跨页 | 题干 |
| 为什么框 | 深蓝标题条＋浅蓝底，可跨页 | 教学解释 |
| 核心结论/错误 | 琥珀标题条＋淡黄底 | 注意/结论 |
| 暂停练习 | 青绿标题条＋浅蓝底 | 互动自测 |

## 设计原则

1. 正文阅读优先。数学陈述、公式以及推理不挤到页边；尽量避免一行里塞入过长公式。
2. 标题一页出现频率适中，勿将每段变成大色块；约每 1--2 页点缀一个语义提示框即可。
3. 题目可以有边框，证明应主要在正文流里，让读者能顺着阅读，而不是每一步都装一个框。
4. 不用截图代替公式； LaTeX 是唯一的公式母版，保留矢量文字和可检索文本。
5. 所有数学环境提供足够上下留白；表格行距合理，表头可清晰辨认。
6. 插图必须具备教学价值（坐标轴/变化过程/依赖图等），不为装饰增加随机图库。
7. 跨页长框由 `breakable` 处理；长公式用 `align` / `multline` 手动择行，禁止缩放为蚂蚁字。
8. 颜色只承担语义：青绿=题目与结构；深蓝=原理解释；琥珀=重点/误区。
9. 不要动 `templates/course-style.sty` 的版式参数。日后需要新增布局时，通过新增受控组件并增补该文件完成版本升级。

## 组件用法

```latex
\begin{questionbox}[黑板例题] ... \end{questionbox}
\begin{whybox}[为什么这样做？] ... \end{whybox}
\begin{takeawaybox}[抓住这一点] ... \end{takeawaybox}
\begin{trybox}[暂停 30 秒：自己试试] ... \end{trybox}
\begin{trapbox}[常见错误] ... \end{trapbox}
\stephead{第 1 步：翻译题目。} 后面接自然行文。
```

## 截图抽样 QA

推荐渲染缩略图以便第一轮检查；最终逐页检查放大的实际效果，关注封面主标题不被装饰圆遮挡、所有提示框右边界齐平、数学符号不挤、图片和表格不贴页脚。输出目录的 `contact-sheet.png` 可供一次性纵览。

对于短讲义，如果详细目录被拆到一个几乎空白的第二页，允许在正文 `\tableofcontents` 前设置 `\setcounter{tocdepth}{1}`，只显示章/节主标题；这是内容密度控制，不改变设计系统。
