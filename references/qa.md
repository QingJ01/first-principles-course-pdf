# 教学正确性 + PDF 质量验收

## A. 事实和证明

- [ ] 所有输入题目/板书均已转录，编号可追踪，遮挡处没有暗中猜写。
- [ ] 出现的每个记号有定义；量词、定义域、参数范围明确。
- [ ] 每个定理与技巧列出全部先决条件；本节之前已讲或已明确给出可接受的基础事实。
- [ ] 每一处“因此”有可查证的推理；没有从结论直接倒推。
- [ ] 反证法的矛盾句完整，根数证明的非零条件已检查。
- [ ] 已尽力做符号计算/边界例子核验，数值验算不冒充严格证明。
- [ ] 未将“无有理根”错误地推广至四次及以上多项式不可约。
- [ ] 配套反例正确；反例不能违背题目原有假设。
- [ ] 练习题覆盖每个核心目标，答案比题干更详细，而非结果汇总。
- [ ] 语言对零基础读者友好，但证明的核心逻辑不省略。

## B. 视觉和构建

- [ ] 使用固定 `course-style.sty`，A4、不低于 12pt 正文。
- [ ] PDF 实际页数非零，可检索文字，中文没有方框/乱码。
- [ ] 至少编译两轮，目录页码与交叉引用完成。
- [ ] LaTeX 日志无未定义命令/引用，overfull 已检查并修复严重项。
- [ ] 全部页渲染通过，无截断、重叠、空白异常页、图框溢出。
- [ ] 封面标题未被圆形遮挡、封面底部文案不贴边。
- [ ] 字体、色值、框体颜色和页眉/页脚与模板一致。
- [ ] 大公式正确断行；根号上下标、分式和矩阵足够清晰。
- [ ] 最后一页不出现只有一两行文字的孤页（尽量修复）。

## C. 课程体验

- [ ] 学生第一次遇到的抽象概念有直觉例子。
- [ ] 每个例题解释“为什么想到这个方法”，而不只有标准解。
- [ ] 每节有可暂停练习；有 A/B/C 练习、详解、判题路线图或回顾。
- [ ] 整节课遵循从简单到困难的依赖顺序。
- [ ] 学完后学生能处理至少一类没在例题出现过的题型变式。

## 构建异常分类

- `xelatex command not found`: 安装 XeLaTeX 与 ctex/xeCJK。
- `font "Noto ..." cannot be found`: 安装 Noto CJK 中文字体（勿在仓库中分发字体二进制）。
- `Undefined control sequence`: 先检查模板宏名或忘记载入样式文件。
- `Missing character`: 检查特殊符号、字体与 TeX 转义。
- `Overfull \\hbox`: 对过长的公式使用 `aligned`/`multline`，修复后重新编译；不要一味缩小字号。
- 空白页异常或部分文本在页外：通过 `preview/pages` 的渲染逐页检查，不能只信编译成功。
